# AsBuild demo (TypeScript)

A small React and TypeScript app, made with Vite, whose pull requests will show [AsBuild](https://github.com/hevelius-ai/asbuild)'s verdicts on a TypeScript project. AsBuild checks an AI agent's pull request against tests a person approved, and records the result in a plain receipt. What it is, how to install it and what it does not prove: [AsBuild's README](https://github.com/hevelius-ai/asbuild#readme).

The same four verdicts on a Python project: [asbuild-demo](https://github.com/hevelius-ai/asbuild-demo).

## Try the app

With Node.js 24 or newer and npm 11.19 or newer:

```bash
npm ci
npm run dev
```
